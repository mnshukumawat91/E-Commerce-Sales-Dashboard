# E-Commerce-Sales-Dashboard
Excel Sales Dashboard With Pivot Tables, Pivot Charts And Slicers

Interactive Excel dashboard built with Pivot Tables, PivotCharts and Slicers.

![Dashboard](dashboard.png)

## Features
- KPI cards: Total Sales, Total Profit, Profit Margin
- Category slicer that filters the whole dashboard
- 6 charts: Monthly Trend, Profit by Category, Sales by Category, Sales by Region, Top 10 Products, Top 10 Cities

## Tools
Excel, Pivot Tables, PivotCharts, Slicers
